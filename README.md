# 200 squares

Frontend prototype: 199 squares and one daily banner. Next.js + TypeScript + Tailwind, all data mocked in the browser.

Planning lives in `.scratch/200squares-frontend/map.md`. Vocabulary lives in `CONTEXT.md`.

## Develop

```bash
npm install
npm run dev
```

Nothing is viewed locally — every visual check happens on a Vercel preview URL. Push a branch and open the preview.
